# My First Calculator

A web calculator with a pixel-art design, built with vanilla HTML, CSS, and JavaScript.

**Live demo:** [Try the calculator](https://delgadowrites.github.io/calculator/)

## Features
- Add, subtract, multiply, and divide (+ − × ÷)
- Chain operations left to right (e.g., 2 + 3 + 4 = 9)
- Decimal support, with results rounded to 8 decimal places (0.1 + 0.2 shows 0.3)
- Error handling for division by zero
- CLEAR button that fully resets the calculator
- Typed numbers limited to 12 characters; long results wrap inside the display

## What I Learned
- Handling button clicks with event listeners
- Updating the page with JavaScript (DOM manipulation)
- Tracking calculator state with variables and true/false switches
- Testing edge cases and re-testing old features after every change (regression testing)
- Debugging independently: predicting results, testing, and isolating bugs
- Version control habits: small commits, CHANGELOGs, and publishing with GitHub Pages
